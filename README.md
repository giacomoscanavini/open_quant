# OpenQuant Numerical Solutions

This folder contains scripts for numerically solving problems from the **OpenQuant** website (https://openquant.co/questions).

The goal of this folder is to provide reproducible, code-based solutions to the problems provided by the website approaches on topics including probability, statistics, optimization, stochastic processes, numerical methods, and other topics commonly encountered in quantitative finance and technical interview preparation.

Note that not all problems require a numerical solution proof or optimization result so some might be missing.

## Purpose

The scripts in this folder are intended to:

- Solve OpenQuant problems using numerical or simulation-based methods
- Verify analytical solutions when possible
- Provide clear, readable implementations for future reference
- Serve as a personal study archive for quantitative problem solving

## How to Run

All scripts can be run directly from the command line:

```bash
python problem_001.py
```

The parameters of the simulations (e.g. number of simulations) can be changed directly inside the script.

## Requirements

The required Python packages may vary by script. Common dependencies may include:

```text
numpy
scipy
pandas
matplotlib
```

## Disclaimer

These scripts are for personal study and educational purposes. They are independent numerical implementations and should not be treated as official OpenQuant solutions unless explicitly stated by the problem source.
